* **Frontend:** Estrutura semântica com **HTML5** e estilização avançada via **CSS3** (Variáveis nativas, Grid e Flexbox).
* **Engine:** Lógica de interface e manipulação de DOM baseada em **JavaScript ES6+**.
* **Deploy:** Configurado com **Continuous Deployment (CD)** via Vercel.

---

## ✨ Interface e UX

* **🎨 Visual minimalista:** tema escuro acinzentado, tipografia limpa (Inter + JetBrains Mono) e um único tom de destaque.
* **📱 Responsivo:** layout adaptado para desktop e celular, com menu recolhível.
* **⚡ Leve:** sem frameworks nem bibliotecas; animações discretas com **IntersectionObserver** e destaque automático da seção atual no menu.
* **♿ Acessível:** foco visível no teclado e respeito à preferência de movimento reduzido do sistema.

## 📁 Estrutura do Projeto

O projeto adota o conceito de **Single File Application** para simplificar a manutenção e reduzir latência:

```bash
portfolio/
├── index.html      # Toda a lógica de UI, estilos (CSS) e scripts (JS)
├── vercel.json     # Regras de roteamento e configurações de deploy
└── README.md       # Documentação técnica do projeto
```
